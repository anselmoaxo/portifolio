# Como contribuir

1. Faça um fork e crie uma branch a partir de `main`.
2. `npm ci` e `npm run dev` para rodar localmente.
3. Antes de abrir o PR, rode `npm test` (type check + build).
4. Abra um Pull Request descrevendo a mudança.

Para adicionar um projeto, crie um arquivo em `src/content/projects/` seguindo os existentes. Veja o README para detalhes da estrutura.
